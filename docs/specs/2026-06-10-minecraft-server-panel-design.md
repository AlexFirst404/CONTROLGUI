# CONTROLGUI — локальная панель управления Minecraft-серверами

Дата: 2026-06-10. Статус: реализовано (v1).

## Цель

Локальный сайт, через который можно создавать, настраивать, запускать и удалять
настоящие Minecraft-серверы на этой машине. Интерфейс стилизован под Minecraft.

## Допущения (сессия фоновая, уточнить было не у кого)

- Папка `D:\MinecraftUI\site` была недоступна из песочницы (запрет на чтение и
  копирование), поэтому Minecraft-стиль воссоздан с нуля в `public/css/minecraft.css`
  и `public/js/textures.js`. Слой стилей изолирован — его можно заменить на готовый
  UI-кит без изменения логики.
- Бэкенд — Node.js ≥ 18 без npm-зависимостей (чтобы запускалось одной командой).
- Для запуска серверов нужна Java (для MC 1.20.5+ — Java 21). Панель проверяет
  наличие Java и предупреждает.
- Язык интерфейса — русский.

## Архитектура

```
server.js            — входная точка, http-сервер на порту 8400
lib/paths.js         — пути (data/, servers/), создание каталогов
lib/store.js         — реестр серверов (data/servers.json)
lib/properties.js    — парсинг/генерация server.properties
lib/download.js      — списки версий и скачивание jar (Mojang piston-meta, PaperMC v2)
lib/manager.js       — процессы java: запуск/стоп/команды, буфер консоли, SSE, игроки
lib/api.js           — REST + SSE маршруты
lib/static.js        — раздача public/
public/              — SPA: index.html, css/minecraft.css, js/{textures,api,app}.js
servers/<id>/        — каталоги реальных серверов (jar, мир, конфиги)
data/servers.json    — реестр
```

## API

- `GET  /api/status` — наличие/версия Java, LAN-адреса.
- `GET  /api/versions/vanilla|paper` — списки версий (кэш 10 мин).
- `GET  /api/servers` — список с рантайм-статусом (stopped/starting/running/
  stopping/downloading/no-jar/error), игроками и прогрессом загрузки.
- `POST /api/servers` — создание: имя, тип (vanilla/paper), версия, порт, память,
  режим, сложность, max-players, MOTD, сид, online-mode, pvp, принятие EULA
  (обязательно — иначе 400). Каталог + eula.txt + server.properties создаются сразу,
  jar качается асинхронно с прогрессом.
- `GET/DELETE /api/servers/:id` — детали / удаление (только остановленный).
- `GET/PUT /api/servers/:id/properties` — чтение/правка server.properties
  (+ имя и память панели).
- `POST /api/servers/:id/start|stop|kill|restart|command|download`.
- `GET  /api/servers/:id/console` — SSE: реплей последних 1000 строк, затем live,
  heartbeat 25 с.

## Управление процессом

`spawn('java', ['-Xms512M', '-Xmx<mem>M', '-jar', 'server.jar', 'nogui'])` в каталоге
сервера. Статус `running` по строке `Done (...s)!`; игроки — по `joined/left the game`.
Остановка — `stop` в stdin, принудительно kill через 30 с. ENOENT java → статус
error с подсказкой об установке Java.

## UI (экраны)

1. **Список серверов** — как экран мультиплеера: строки с иконкой травяного блока,
   именем, версией, MOTD, статусом и числом игроков; кнопки Создать/Обновить/
   Управлять/Удалить; двойной клик открывает сервер.
2. **Создание сервера** — как «Создание мира»: поля + циклические кнопки MC
   («Режим игры: Выживание»), чекбокс EULA, после создания — прогресс-бар загрузки jar.
3. **Сервер** — вкладки: Консоль (чёрная панель + ввод команд с историей),
   Настройки (известные ключи формой + остальные сырым текстом, предупреждение о
   перезапуске), Информация (адрес для подключения, путь к файлам, опасная зона
   с удалением).

Текстуры (тёмная земля для фона, камень, иконка-блок травы, favicon) генерируются
на canvas с сидированным ГПСЧ — сайт полностью работает офлайн; пиксельный шрифт
Press Start 2P подгружается с Google Fonts при наличии сети, иначе моноширинный fallback.

## Обработка ошибок

- Конфликты: запуск во время загрузки jar, удаление работающего, повторный запуск — 409.
- Обрыв загрузки jar → статус error + кнопка «Скачать заново» (`POST .../download`).
- Все ошибки API показываются тостами в стиле MC.
