# Полное удалённое управление через сайт (reverse-proxy поверх туннеля)

Дата: 2026-06-27. Статус: одобрено пользователем.

## Цель
Дать на сайте CONTROLGUI Remote (`https://89.125.169.61`) **полноценное управление сервером
«как в приложении»**: консоль, команды, файлы (правка/просмотр), игроки, настройки,
плагины/моды, мониторинг, бэкапы (создание/восстановление) — удалённо, через существующий
исходящий SSE-туннель. Без npm-зависимостей.

## Решения (от пользователя)
- **Охват:** всё, кроме тяжёлого/опасного. Исключено удалённо: удаление сервера,
  бинарные загрузки >50 МБ (`file-upload`, `core`), скачивание бэкапов/больших файлов.
- **UI:** переиспользовать интерфейс панели (`public/`) 1:1.
- **Права:** владелец/админ — полный доступ; назначенным выдаётся подмножество из
  ПОЛНОГО списка прав панели (console.*, files.*, players.*, settings.edit, backups.*…).

## Архитектура (Approach A — прозрачный reverse-proxy)
Транспорт — существующий туннель: SSE вниз (центр→панель) + HTTPS POST вверх. Добавляются
типы сообщений `http` (проксируемый запрос) и `chunk` (потоковый ответ кусками). WebSocket НЕ нужен.

### Обычный запрос
1. Браузер → центр: `GET /r/<globalId>/api/...` (сессия центра, кука `cgr_sid`).
2. Центр: проверяет `canView`; вычисляет набор прав юзера для сервера; денилист «тяжёлого»;
   шлёт в туннель `{reqId, kind:'http', method, path, query, headers, bodyB64, perms:[…]}`.
3. Панель (`lib/remote.js`): loopback-запрос на `http://127.0.0.1:PORT…` с внутренним секретом
   и заголовком прав.
4. Панель (`server.js`): для loopback с валидным секретом — синтетический `cgUser` ровно
   с проброшенными правами → штатный `requirePerm` решает доступ поэндпоинтно.
5. Ответ (status+headers+body) → `POST /agent/result` → центр → браузер.

### Стриминг (консоль SSE, чтение текстового файла, лог)
Центр держит ответ браузера открытым; панель читает loopback-поток, шлёт куски
`POST /agent/chunk {token, reqId, seq, dataB64, done}`; центр ретранслирует. Корреляция по
`reqId` без 15-сек таймаута для потоков. Закрытие вкладки → `stream-close` в туннель → панель
закрывает loopback.

## Безопасность
- **Авторизация на каждый запрос:** центр пускает при `canView`; панель применяет проброшенный
  набор прав своим `requirePerm` (назначенному — только его подмножество).
- **Loopback-доверие:** внутренний секрет генерится при старте панели (per-process), известен
  только `lib/remote.js`, принимается лишь с `127.0.0.1`. Снаружи панель по-прежнему требует логин.
- **Денилист на центре:** `DELETE` сервера, `PUT …/file-upload`, `PUT …/core`,
  скачивание бэкапа/файла >лимита → `403 «недоступно удалённо»`.
- Пиннинг TLS, одобрение аккаунтов админом, антибрутфорс — уже есть.

## Модель прав (расширение центра)
`access[].perms` расширяется с `[start,stop,restart]` до полного списка ключей панели.
Владелец/админ → все права. Экран «Доступ…» на сайте — чекбоксы по группам.
Центр→панель: перм-набор для роли (owner/admin = все; assigned = выданные).

## Интерфейс (1:1)
- Центр отдаёт копию `public/` панели (кладётся при деплое в `central/public-app/`).
- `public/js/api.js`: поддержка `window.CG_API_BASE` (по умолчанию `''` — локально без изменений;
  на сайте `/r/<globalId>`), включая `EventSource`. Единственная правка фронта панели.
- Флаг `window.CG_REMOTE=true` прячет несовместимые пункты (управление юзерами панели,
  launch-mode, установка Java, удаление сервера).
- Страница `central/public/manage.html` грузит `app.js` с выставленными `CG_API_BASE`/`CG_REMOTE`.

## Компоненты (изолированно)
- `central/lib/proxy.js` — маршрут `/r/:gid/*`, авторизация, денилист, ретрансляция (вкл. стриминг).
- `central/lib/agents.js` — `dispatchHttp`, приём `chunk`, потоковые pending без таймаута.
- `lib/remote.js` — обработчик `http`/`stream-close`, loopback-клиент, отправка чанков.
- `server.js` (панель) — доверие внутреннему loopback-принципалу с набором прав.
- `central/lib/servers.js` / `accounts.js` — права = полный список; `canDo` обобщён.
- UI: `central/public/manage.html`, правка `public/js/api.js`, флаг remote.

## Ошибки / тесты
Туннель офлайн → 502; таймаут обычных запросов 15с, потоки — без; закрытие потоков по дисконнекту.
Тесты (локально + вживую): прокси GET (список/файлы), консоль SSE (команда→строки), правка файла,
действие над игроком, **заблокированная операция → 403**. Адверсариальный воркфлоу-ревью перед деплоем.
